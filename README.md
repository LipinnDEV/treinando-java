# Treinando Java

Repositório criado para registrar minha evolução durante os estudos de Java.

Aqui estão alguns dos exercícios e conceitos que estou aprendendo, desde os primeiros comandos até a criação de pequenos projetos.

## Conteúdos estudados

- Saída de dados com `System.out.println()`
- Variáveis e tipos de dados
- Concatenação de textos e variáveis
- Entrada de dados com `Scanner`
- Condicionais com `if`, `else if` e `else`
- Operadores de comparação
- Exercícios práticos de lógica de programação

## Tecnologias

- Java
- Git e GitHub

## Objetivo

Praticar programação, desenvolver meu raciocínio lógico e acompanhar minha evolução como estudante de Desenvolvimento de Sistemas.

Este repositório está em constante atualização conforme avanço nos estudos.
